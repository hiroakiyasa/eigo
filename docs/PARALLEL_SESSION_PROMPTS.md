# 20セッション用・コピー開始プロンプト

対応するコードブロックを新規ChatGPTセッションの最初のメッセージとしてそのまま貼り付ける。各セッションは、1回の実行で固定担当範囲内の未完了ページを最後まで処理する。完全な仕様と担当範囲はリポジトリから取得するため、チャット間で内容が欠落しない。

## S01 — PAGE_0054〜PAGE_0067

```text
GitHubリポジトリ hiroakiyasa/eigo の20並列問題制作セッション S01 として開始してください。main上の AGENTS.md、docs/PARALLEL_SESSION_SYSTEM_PROMPT.md、data/parallel-question-assignments.json を全文読み、S01 の固定担当範囲だけで、記載された全手順を確認質問なしで直ちに実行してください。1回の実行で担当範囲内の未完了ページを最後まで完成させ、5ページなどの途中上限で停止しないでください。
```
