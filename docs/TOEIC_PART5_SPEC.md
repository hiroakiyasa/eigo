# 4択文法マスター問題・品質基準

## 40問の形式内訳

参考写真とIIBC公式サンプルの構造を中心にしながら、1ページ40問を以下の固定構成にします。すべて4択で正解は1つです。

- `part5-cloze` 10問: 独立した英文1文の空所を語または句で補う。
- `correct-sentence` 10問: 4つの英文から、文法・意味ともに正しい文を選ぶ。誤りを見抜く力を試す。
- `meaning-equivalent` 10問: 基準文と同じ意味を保つ英文を選ぶ。時制、態、比較、節などの形と意味の対応を試す。
- `context-completion` 10問: 2〜3文の短い文脈内にある空所を補う。前後関係を使った運用判断を試す。

`part5-cloze` と `context-completion` の空所表記は半角ハイフン7個の `-------` に統一します。`correct-sentence` と `meaning-equivalent` の選択肢は、原則として完全な英文にします。

全形式共通:

- 選択肢は `(A)`〜`(D)` の4つに相当する語、句、または文とする。
- 文法・語法・意味・文脈から最適なものを1つだけ設ける。
- 問題文と選択肢はすべてオリジナルにする。

## ページとの関係

- 40問すべてが対象ページの中心テーマ、例、注意点、対比のいずれかを実際に問うこと。
- 図鑑の例文をそのまま穴埋め化せず、語彙・主語・場面を変えた新しい文脈で理解を試すこと。
- TOEICで自然な職場、連絡、出張、買い物、施設、サービス、日常業務などの文脈を優先する。
- 表紙・目次・まとめページでは、ページに見える複数の学習テーマから出題範囲を定義し、`analysis.summaryJa` に理由を書く。
- 絵の物体名を当てる問題ではなく、絵が説明している英語知識を問う。

## 難易度の固定配分

各ページ40問の難易度は、TOEIC L&Rで幅広い能力帯を識別しやすい問題群にするため、次の比率に固定する。

- `basic`: 10問（25%）— TOEIC L&Rのおおむね初級〜基礎帯を意識。基本語順、基本語形、頻出文法を明確な手掛かりから判断する。
- `intermediate`: 20問（50%）— 中間層を最も細かく識別する中心帯。品詞・時制・語法・節構造などを、自然な業務文脈ともっともらしい誤答の中から判断する。
- `advanced`: 10問（25%）— 高得点層を識別する発展帯。複数の文法手掛かり、意味・文脈、紛らわしい語法を組み合わせて判断する。ただし対象ページの学習範囲を超える知識だけで難しくしない。

各形式10問の中でも原則 `basic` 2〜3問、`intermediate` 5問、`advanced` 2〜3問とし、4形式を合計したとき必ず10/20/10問にする。難易度ラベルは単なる語彙の難しさではなく、判断に必要な文法処理・文脈処理・誤答の紛らわしさで決める。

この40問セット単独の正答数を公式TOEICスコアへ直接換算してはならない。公式TOEIC L&RはListeningとReadingを合わせた別形式・別問題数の尺度であり、本問題群は文法力の推移や能力帯を推定するためのデータとして利用する。将来スコア推定機能を実装する場合は、多数の受験者について本問題の正誤データと実際のTOEIC L&Rスコアを収集し、項目難易度・識別力を校正して換算モデルを作る。

## 40問の品質

- 問題数と形式内訳は必ず上記の40問にする。
- 難易度は必ず `basic` 10問、`intermediate` 20問、`advanced` 10問にする。
- 正答位置は全体で A・B・C・D を各10問にする。各形式内でもA〜Dがそれぞれ2〜3問になるようにし、規則的な並びにはしない。
- 同一の問題文、ほぼ同じ構文、同じ選択肢セットを繰り返さない。
- 各問は正解が1つに確定し、ほかの選択肢が文脈次第で成立する曖昧さを残さない。
- 語形問題では同じ語族、接続表現では意味の近い表現など、もっともらしい誤答を置く。
- 固有の会社名や人物名は架空にし、差別的・危険・政治的な題材を避ける。
- `translationJa` は正答を入れた英文全体の自然な和訳にする。
- `explanationJa` は「なぜ正解か」に加え、必要なら主要な誤答がなぜ不適切かも簡潔に説明する。
- `focus` には、その問が検証するポイントを具体的に書く（例: `形容詞と副詞の選択`）。
- `part5-cloze` は参考写真のような短く明確な4択穴埋めにするが、写真内の問題文は転用しない。

## 深い理解として残す分析

問題セットの `analysis` には以下を残します。

- `summaryJa`: ページが伝える仕組みを、自分の言葉で要約。
- `grammarPoints`: 問題化する文法・語法上の要点。
- `visualEvidence`: 画像内の図、対比、例文、注意書きのうち判断根拠にしたもの。
- `commonTraps`: 学習者が誤りやすく、誤答設計に利用した点。

単に原稿を要約するだけでは不十分です。画像と原稿の食い違いを確認し、問題40問が各要点をどうカバーするかを考えてから作成します。
