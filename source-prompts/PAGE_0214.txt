Top Japanese title: 「whichは文全体も受ける」

Teach comma + which as an annotation receiver. Central three-way funnel: noun/part of a set → property/expression → entire preceding event, all flowing into WHICH. Include preposition + which and quantity + of which patterns.

Original examples:
• We bought four lamps, two of which were damaged. 「4個のうち2個」
• This camera, for which I paid a lot, stopped working. 「そのカメラに大金を払った」
• Mia solved the puzzle in one minute, which amazed everyone. 「出来事全体が皆を驚かせた」
• Leo was unusually quiet, which he rarely is. 「quietという状態を受ける」
